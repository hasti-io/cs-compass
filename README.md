# cs-compass

CS Compass is a beginner-friendly website designed to help high school students figure out where to start in computer science. It includes roadmaps, course reviews, reflections, internship lists, and monthly updates documenting the growth of the project.

## Features
- Beginner CS roadmaps
- AP CSA review
- Personal reflections
- Internship and project idea lists
- Growth timeline and monthly updates
- Advice

## Tech Stack
- HTML
- CSS
- JavaScript
- GitHub Pages (hosting)

## Purpose
I built CS Compass based on my own CS journey to help other students avoid confusion and find clear, realistic guidance.
